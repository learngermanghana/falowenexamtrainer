## A1 Days 2–3 (2026-11-02) content synchronization

The ChatGPT lesson-content snapshot is generated by `scripts/generateChatgptLessonContent.mjs` at build time. For A1 tutor assignments, it must use **`A1_ASSIGNMENT_ORDER`**, not every registry entry: the registry intentionally retains historical assignments.

- Day 2 current workbook: `A1-0.2_1.1`, one five-section combined alphabet, pronouns and first-verbs assessment. Old `A1-0.2` and `A1-1.1` submissions remain historical; the Companion must not list them as current or advertise their old Hören or teaching videos.
- Day 3 current workbook: `A1-1.2`, unchanged Lesen/Schreiben/Hören assessment, with starter W-question words `wie, wo, woher` in grammar. Full W-question teaching is reserved for Day 5.
- Do not assume that Google Drive spreadsheets or Google Calendar are synchronized by this generated snapshot. Teaching timetables are read from verified Falowen class records when the user invokes the relevant tool; separate external calendar entries require their own established source and workflow.
- Verify `get_my_falowen_lesson` and `get_my_falowen_lesson_content` for days 2 and 3 **after production deployment**, not just in tests.


## B2–C2 Course Book expansion (2026-11-03)

The Falowen MCP tool always resolves enrolled level from the OAuth student record, never from a requested level argument.

- **B2:** 28 original lessons with genuine reading text/questions on assigned Lesen days. Day 20 is Schreiben, not Lesen.
- **C1:** 28 aligned self-study days with grammar focus, writing prompts, course phrases and review tasks. Original C1 Days 1–16 reading assignments can be returned, but their source contains no reading passages or graded question banks. Days 17–28 have no exported reading passages. Do not invent them.
- **C2:** 28 days follow a rotating skill schedule: Lesen (1, 5, 9, 13, 17, 21, 25); Hören (2, 6, 10, 14, 18, 22, 26); Sprechen (3, 7, 11, 15, 19, 23, 27); Schreiben (4, 8, 12, 16, 20, 24, 28). Only actual Lesen days export source passages and unanswered questions.
- The section named reading maps to Lesen, speaking to Sprechen. Request one section at a time. Missing sections return unavailable.
- Exported material is explicitly allowlisted: never include answer indices, private solutions, model answers, teacher notes, or audio transcripts.
- Course content is generated during the existing build, without additional Firestore reads or an AI service. Campus remains responsible for submitting, grading and verifying completion.

For release verification, regenerate the snapshot, run unit and authenticated HTTP tests, then verify with C1/C2 student logins and check C2 Day 1 Lesen, C2 Day 20 Schreiben, C2 Day 20 Lesen unavailable, and cross-level spoofing. A GitHub merge is not proof of a production deploy or public Plugin Directory publication.
