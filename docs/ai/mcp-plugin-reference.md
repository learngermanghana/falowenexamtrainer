## Interactive exam-practice protocol (2026-11-03)

- `get_my_falowen_practice_guide(day, skill, mode?, language?)` is a new **read-only** tool. It resolves the level from the OAuth student record, supports reading/listening/speaking/writing/grammar, and returns an exact section with a conversation-based one-question-at-a-time protocol. The student's own ChatGPT responses are used for feedback; this endpoint does not run a separate server AI model.
- In older plugin connections exposing only `get_my_falowen_lesson`, the `featuredCourseBookSection` and `practiceSuggestion` remain the compatibility entry point. The new dedicated tool may require a manual OpenAI plugin manifest refresh/review; deploying the backend does **not** force an installed ChatGPT connection to gain newly named tools.
- **C1** reading practice content lives in `web/src/data/c1ReadingPractice.js`. Campus uses the same source via `C1ReadingPracticePanel.jsx`. Text responses remain in the component's local state and are neither submitted to Campus nor converted to an official grade. No automated correctness claim is made for free-text questions.
- **Hören**: Only point students to verified Campus audio when source `audioAvailableInCampus` is true. Do not fabricate an external MP3 URL or reveal hidden listening transcripts. C1 does not yet export verified lesson audio; a source-link/recording integration is a separate task.
- **Sprechen/Schreiben**: The plugin shares original prompts and a feedback rubric; ChatGPT's written coaching is not official Campus marking. Pronunciation feedback requires actual user audio, not guessed pronunciation.
- **Grammar**: `language=en` requests English *explanation* of existing German content; it does not change the underlying course text or require a translation API call.
- **Practice summaries** are conversation-only until student-approved cross-device sync is implemented with a separate consent and data-retention design. Never persist private model conversations, auto-generate official scores, or infer self-study completion.
- Maintain the no-answer-index export check and OAuth level-scope tests; rebuilding the canonical snapshot is part of existing Vercel prebuild. No additional scheduled job or paid background model calls have been added.

## Exam coaching and optional practice notes — 14 November 2026 (PR, not yet published)

- `get_my_falowen_exam_practice(mockId, skill, part?)` is a read-only A1/A2 selected mock *writing/speaking* prompt export. The source is the canonical `functions/data/assessmentTasks.json` exam registry, but output fields are strictly allowlisted. It does not expose reading/listening keys, secret rubrics, answers, audio URLs, unreleased mock drafts or another enrolled level. Lesen/Hören require a separate student-facing, answer-safe question/audio export before enabling one-question-at-a-time practice.
- `save_my_falowen_practice_note(day, skill, note, requestId)` is an **optional student-initiated write** requiring OAuth scope `falowen:practice:write` in addition to `falowen:read`. Existing read-only connections remain read-only. This records only a bounded self-reported practice note under token-derived identity; it never mutates grades, exams, assignments, answer keys, payments or attendance. A request ID makes retries idempotent. Records include 90-day expiry metadata; Firestore TTL policy must be enabled separately.
- The publisher must request reapproval for newly exposed tools and write permission and verify fresh consent flow, revoke/reconnect behavior and student isolation. A ZIP upload does not activate a new scope; the OpenAI portal's plugin snapshot must also include/approve the new tool metadata.
- **Do not claim official exam result upload.** Written or spoken student answers may be reviewed conversationally in ChatGPT; only an explicit save request writes the optional note.
