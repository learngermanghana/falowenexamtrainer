# Class members placement

- The home dashboard shows a compact `Your class` preview after the welcome/payment area and before Campus/Exams access.
- The Course Book no longer exposes a duplicate full directory; it shows a compact `View classmates` shortcut.
- `/campus/discussion?tab=members` opens the full class directory.
- Class preview cards use public profile fields only and do not display email addresses.
- B2 and C1 self-learning accounts do not receive the class preview unless the class-track rules change later.
